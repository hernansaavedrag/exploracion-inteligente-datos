
# Exploración Inteligente para la Ciencia de Datos

## Magíster en Ciencia de Datos e Inteligencia Artificial
Universidad Andrés Bello (UNAB)

**Asignatura:** MCDI503 - Exploración Inteligente para la Ciencia de Datos

**Proyecto:** Análisis exploratorio reproducible de los factores asociados a la supervivencia de pasajeros del Titanic.

## Integrantes
- Hernán Saavedra
- Lenin Morales
- Rodrigo Gómez

## Objetivo
Realizar un análisis exploratorio de datos (EDA) sobre el conjunto de datos Titanic, identificando patrones asociados a la supervivencia, evaluando la calidad de los datos y documentando las decisiones metodológicas para garantizar la reproducibilidad.

## Tecnologías
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Organización
El proyecto se desarrollará colaborativamente mediante GitHub, utilizando ramas individuales y Pull Requests.
